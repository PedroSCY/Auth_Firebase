# Firebase Authentication: Aprendizado e Prática

Bem-vindo ao meu repositório de estudos sobre autenticação com Firebase
Aqui exploro na prática como implementar e gerenciar autenticação de usuários utilizando os serviços do Firebase.

### Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de entender, na prática, como funciona o processo de autenticação em aplicações modernas.

A proposta é implementar fluxos reais de login, registro e validação de usuários, utilizando o Firebase como provedor de autenticação, simulando cenários comuns de aplicações backend.

### O que você encontrará aqui?  

✔️ Cadastro de usuários (sign up)  
✔️ Autenticação de usuários (login)  
✔️ Validação de sessão/token  
✔️ Proteção de rotas  
✔️ Integração com Firebase Authentication  
✔️ Manipulação de credenciais de forma segura  
✔️ Tratamento de erros de autenticação  
✔️ Organização de código e separação de responsabilidades  
✔️ Login(google,github,telefone,sem senha...)  

### O que estou praticando?
Fluxos de autenticação modernos  
Uso de Firebase Auth  
Segurança em aplicações backend  
Integração com serviços externos  
Controle de acesso e autorização  
Estruturação de código voltado para autenticação  

### Tecnologias Utilizadas
Node.js

### Como executar o projeto

Instalar dependências  
npm install  

Rodar o projeto  
npm run start  

É necessário configurar as credenciais do Firebase no ambiente antes de executar.

### Por que estudar autenticação?

A autenticação é um dos pilares de qualquer aplicação moderna.
Entender como gerenciar usuários, proteger rotas e garantir segurança no acesso é essencial para qualquer desenvolvedor backend.

Consolidar conhecimentos em autenticação
